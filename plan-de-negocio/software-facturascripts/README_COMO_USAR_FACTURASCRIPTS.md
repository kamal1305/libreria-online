## 1. ¿Qué es FacturaScripts?
FacturaScripts es un software de gestión empresarial y facturación de **código abierto (Open Source), 100% gratuito y desarrollado en España**. Es especialmente popular en librerías, papelerías y comercios minoristas porque:
* Cumple al 100% con la normativa fiscal española (Ley Antifraude, Factura electrónica, IVA desglosado por tipos: 4%, 10%, 21%).
* Permite gestionar clientes, proveedores y catálogos de libros.
* Permite generar tickets de venta simplificados para mostrador o tienda online.
* Dispone de plugins gratuitos para TPV (Terminal Punto de Venta) con lector de código de barras.

---

## 2. Cómo se puede poner en marcha en Windows

FacturaScripts es una aplicación web escrita en PHP/HTML. Para ejecutarla en tu ordenador tienes dos alternativas muy sencillas:

### Alternativa A (La más cómoda con un solo clic):
1. Puedes descargar el instalador directo para Windows desde su web oficial:
   👉 **https://facturascripts.com/descargar**
2. Ejecutas el instalador en Windows y te creará un acceso directo en tu escritorio como cualquier programa habitual.

### Alternativa B (Descomprimiendo este archivo con XAMPP / PHP):
1. Descomprimes el archivo `FacturaScripts_v2026_CORE.zip` en cualquier carpeta de tu ordenador.
2. Si tienes PHP o XAMPP instalado, ejecutas en la terminal:
   ```bash
   php -S localhost:8000
   ```
3. Abres el navegador en `http://localhost:8000` y se iniciará el asistente de configuración guiada en español.

Para el volumen de ventas inicial, **la vía más rápida, limpia y sin complicaciones técnicas es utilizar la plantilla Excel** que te he preparado en la carpeta superior:
📊 `Plantilla_Control_Fiscal_y_Ventas_Mas_Que_Libros.xlsx`

* Abre directamente en Microsoft Excel, LibreOffice o Google Drive.
* Tiene calculadas automáticamente las casillas del Modelo 303 (IVA al 4% y 21%) y del Modelo 130 (IRPF al 20%).
* Cuando el volumen de ventas supere los 100 libros al mes o abráis el local físico, FacturaScripts será vuestro gran aliado para conectar el datáfono, cajón portamonedas e impresora de tickets.
